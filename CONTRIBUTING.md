# Contributing Guide

Спасибо, что хотите улучшить репозиторий. Ниже — как сделать это правильно.

## Что принимается

- Исправления ошибок в разборах (фактические неточности, неправильный код, опечатки)
- Новые вопросы с разбором в стиле репозитория
- Новые задачи в `tasks/` — полноценные Cargo-проекты с тестами
- Дополнения к theory-файлам
- Улучшения CONTRIBUTING.md или README.md

## Что не принимается

- Контент только на английском (репозиторий на русском)
- Вопросы-угадайки («что выведет эта программа») без практического смысла
- Дубликаты существующих вопросов
- AI-клише и вода без практического примера

## Как добавить вопрос

1. Откройте issue с заголовком «Вопрос: [тема]» и кратким описанием
2. Обсудите место вопроса в структуре
3. Отправьте PR с изменениями в `README.md`, `QA.md`, `ANSWERS.md`

Каждый вопрос должен содержать:
- Чёткую формулировку
- Развёрнутый ответ с объяснением механики
- Рабочий пример кода (компилируется на stable Rust, если не указано иное)
- Комментарий — на что обратить внимание в примере

## Как добавить задачу

Задача — полноценный Cargo-проект в `tasks/NN-название/`:

```
tasks/NN-название/
├── README.md        # условие, наивная попытка, разбор, подводные камни
├── Cargo.toml       # [package] name = "название", edition = "2021"
├── src/
│   └── lib.rs       # реализация + unit-тесты (#[cfg(test)])
└── tests/
    └── integration.rs  # интеграционные тесты
```

Требования к задаче:
- Все тесты проходят: `cargo test -p название`
- Clippy не ругается: `cargo clippy -p название`
- Для unsafe-кода: `cargo +nightly miri test -p название`
- Уровень указан: Middle (1–10), Senior (11–30), Staff (31–40)

## Стиль

- Без воды. Каждое предложение — про механику или про практику.
- Без AI-клише («безусловно», «несомненно», «в современном мире»).
- Примеры кода — короткие, компилируемые, с комментариями на русском.
- Форматирование: `rustfmt` для кода, обычный markdown для текста.

## Процесс ревью

- Один апрув от мейнтейнера для merge
- PR с изменением существующего вопроса — сначала issue
- Новая задача — PR сразу, issue не нужен
- Стиль и форматирование проверяет CI (clippy + rustfmt)

## CI

При открытии PR запускается:
```
cargo test --workspace
cargo clippy --workspace -- -D warnings
cargo fmt --check
```

Для задач с unsafe дополнительно: `cargo +nightly miri test`.

## Вопросы

Открывайте issue с лейблом `question`. Ответим в течение нескольких дней.
