# Rust Interview Deep Dive

Репозиторий с разбором задач и теоретических вопросов с собеседований на позиции Rust-разработчика уровня middle, senior и staff. Каждая задача оформлена как полноценный разбор от практикующего разработчика: условие, наивная попытка, объяснение почему компилятор недоволен или почему рантайм проседает, корректное решение с тестами и, где уместно, бенчмарк или `cargo asm`.

Это не сборник упражнений в духе «угадай вывод программы». Здесь сценарии, которые реально встречаются в продакшене: lock-free структуры, self-referential типы в async, FFI с тензорными библиотеками, корректный `Send` на гардах через await, memory ordering под `loom`, soundness кастомных коллекций.

## Уровни сложности

**middle** — задачи 1–10, типовые вопросы про владение, заимствование и трейты.

**senior** — задачи 11–30, конкурентность, async, unsafe, производительность.

**staff** — задачи 31–40, дизайн API, тёмные углы компилятора, макросы, FFI, soundness.

## Как работать с репозиторием

Сначала читайте условие задачи и пробуйте решить самостоятельно. Не подсматривайте в `src/lib.rs`, пока не получите рабочую версию хотя бы на бумаге. После этого сравнивайте подход с разбором в README задачи: часто наивное решение компилируется, но содержит UB или плохо масштабируется под нагрузкой. Тесты в `tests/it.rs` запускайте через `cargo test -p <task-name>`, а где есть бенчмарки, прогоняйте `cargo bench`. Для задач с unsafe обязательно прогон под `cargo +nightly miri test`.
